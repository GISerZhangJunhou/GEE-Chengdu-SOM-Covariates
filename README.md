# GEE Chengdu Cropland SOM Covariates

## 项目概述
本仓库为**成都市耕地土壤有机质数字制图研究**配套的环境协变量批量处理代码集，基于 Google Earth Engine 平台实现多源遥感、气候、土地利用数据的自动化预处理与指标计算，输出 5 大类 20+ 个环境协变量，支撑数字土壤制图模型构建与驱动机制分析。

研究背景：面向耕地质量监测与精准采样需求，针对成都平原-山地过渡带地形复杂、协变量多源异构的特点，构建标准化的环境变量生产流水线。

## 脚本说明

| 编号 | 脚本名称 | 核心功能 | 主要输出指标 | 数据源 |
|------|----------|----------|----------------|--------|
| 01 | 多年作物制度变量 | 基于 ChinaCP 产品计算多年种植结构与复种特征 | 单/双/三作频率、水稻/小麦/玉米种植频率、复种指数、轮作稳定性 | ChinaCP 年度作物制度产品 |
| 02 | 多时相植被物候变量 | Sentinel-2 云掩膜与植被指数计算、物候参数提取 | 生长季 NDVI/EVI 均值/中位数/标准差、年振幅、峰值时间、变化趋势 | Sentinel-2 SR Harmonized |
| 03 | 季节性气候水热变量 | TerraClimate 月尺度数据单位换算与生长季统计 | 生长季均温/降水/PET/AET/水分亏缺、气候季节性、干湿比 | TerraClimate |
| 04 | 多时相裸土光谱复合 | 多指数裸土识别 + 多年中位光谱合成 | 裸土中位反射光谱、NDVI/NDWI/NBR2/BSI 指数、有效观测次数 | Sentinel-2 SR Harmonized |
| 05 | 管理代理变量 | 灌溉强度、稻作频率、地表水分指数综合计算 | 多年灌溉均值/趋势、稻作频率、生长季 LSWI 统计与趋势 | ChinaCP、CIrrMap、Sentinel-2 |

## 技术亮点
1. **标准化流水线**：统一投影（EPSG:32648）、统一分辨率（250m）、统一研究区裁剪，所有变量空间严格对齐
2. **严谨的质量控制**：Sentinel-2 采用云概率 + SCL 双掩膜去云，剔除阴影、卷云、冰雪等无效像元
3. **函数化封装**：通用逻辑封装为独立工具函数，代码复用性强，可快速扩展至其他区域
4. **多维度指标**：覆盖频率、强度、趋势、稳定性、季节性等多个维度，充分刻画环境协变量的时空特征
5. **工程化输出**：内置 Export 模块，可一键导出至 Google Drive，直接用于后续建模

## 使用说明
1. 在 Google Earth Engine Code Editor 中新建脚本，复制对应 `.js` 文件代码
2. 修改 `PROJECT_PATH` 为自己的资源路径，替换研究区边界矢量与影像资产
3. 点击 Run 运行，可在地图面板查看可视化结果
4. 取消注释 Export 代码块可将结果导出至 Google Drive

> 注意：脚本中影像与矢量资源路径为私有资产，运行前需替换为对应区域的自有数据路径。
